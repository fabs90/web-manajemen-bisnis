# Safety rules

- Never edit or print `.env` or any secrets files.
- Never run `rm -rf`, `git push --force`, or `git reset --hard`.
- Ask before installing new dependencies.
- Don't modify files in `/vendor` or `/node_modules`.
- Run tests before saying a task is complete.
- Never run `git commit`, `git push`, `git merge`, or `git rebase`.
- Never stage files with `git add` unless I explicitly ask.
- When a task is done, summarize the changes and let me review and commit them myself.
